# TTS Developer Onboarding Guide

Use this skill to explain the two TikTok Shop developer onboarding paths: ISV apps for many sellers and seller-developed custom apps for one seller's own shop.

## Workflow

1. Read `references/onboarding-guide.md`.
2. Identify whether the user is an ISV, a seller developer, or unsure.
3. Explain the correct path, required setup, and review/production implications.
4. Mention that current qualification and review requirements must be checked in Partner Center.
5. If the user asks for API implementation, pair this guide with OpenAPI docs or MCP tools.
